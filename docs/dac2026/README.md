# DAC 2026

This section provides a slim public reference for the DAC 2026 Open Climate
Service workshop.

It focuses on:

- setup
- runnable example payloads
- exact commands
- expected outputs
- basic validation

## Pages

- `Reference`
  Step-by-step commands and expected results for the workshop examples.

- `Example payloads`
  Direct links to the JSON request files used by the examples.

## Suggested order

1. open `Reference`
2. run the commands in order
3. use `Example payloads` when you want to inspect or copy a request file
